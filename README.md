# Tech Stack Recommender — Project 3 (AI Recommendation Logic)

## Files
- `Tech_Stack_Recommender.ipynb` — EDA, feature engineering (TF-IDF), and recommendation logic (Jupyter notebook, already executed with outputs)
- `app.py` — Streamlit GUI for the recommender
- `IT_Job_Roles_Skills.csv` — source dataset
- `vectorizer.joblib`, `tfidf_matrix.joblib`, `job_roles_processed.pkl` — pre-trained artifacts (generated by the notebook, loaded directly by app.py so it starts instantly)
- `requirements.txt` — Python dependencies

## How to Run

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. (Optional) Re-run the notebook to regenerate the artifacts:
   ```
   jupyter notebook Tech_Stack_Recommender.ipynb
   ```

3. Launch the GUI:
   ```
   streamlit run app.py
   ```

4. Open the local URL Streamlit prints (usually http://localhost:8501) in your browser.

## How It Works
1. **Ingestion** — user enters skills (dropdown or typed)
2. **Scoring** — skills converted to TF-IDF vectors, compared to every job role using Cosine Similarity
3. **Sorting** — roles ranked by similarity score
4. **Filtering** — Top-N most relevant roles displayed, with a Cold-Start fallback if no skills overlap
